
# Behavioral Regression Run Records

Store completed baseline/regression run records here.

Each record must use the Baseline Run Record schema and bind results to the exact runtime/execution/configuration state.

Do not store credentials, secrets, or unnecessary Engagement-confidential material.

`KNOWN_GOOD` is valid only when the finalized full record and matching Registry entry share one `FINALIZATION_TRANSACTION_ID` and are canonically finalized together.

Where Git is used, both artifacts must be committed in the same finalization commit.
